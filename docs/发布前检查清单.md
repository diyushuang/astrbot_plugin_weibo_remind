# 发布前检查清单

面向本仓库的发布前自查。每次打 tag / 推送前按顺序过一遍，全部通过再推。

## 一、功能与质量

```bash
pip install -r requirements.txt -r dev_requirements.txt
ruff check . && ruff format --check .
python -m pytest
```

- [ ] `ruff check` / `ruff format --check` 无输出（干净）
- [ ] 用例全绿，无 `FAILED`、无警告新增
- [ ] **再用非本地时区跑一遍**：插件内部一律按 `Asia/Shanghai` 解释正文时间，
      而用例里裸 `datetime.now()` 的 `.timestamp()` 跟随**运行机器的本地时区**。
      开发机通常是 UTC+8（与插件一致，掩盖问题），CI 却是 UTC——本项目曾因此漏掉
      一个只在 UTC 下失败的用例。用例构造时间必须显式带时区（`tests/conftest.py`
      的 `now_cn()` / `CN`）：

  ```bash
  TZ=UTC python -m pytest     # Linux/macOS 与 Windows 均可
  ```

- [ ] 若动过导入相关代码，**单独跑** `tests/test_package_load.py`
      （它用子进程模拟 AstrBot 的 `data.plugins.<插件名>` 包路径加载，
      能挡住"扁平导入能过、线上 ModuleNotFoundError"这一类只在真实加载下暴露的问题）

## 三、敏感信息审查

### 3.1 凭据与密钥

```bash
# 私钥 / 云厂商 Key / 各类 Token
grep -rnE "BEGIN [A-Z ]*PRIVATE KEY|(AKIA|LTAI|AKID)[A-Za-z0-9]{12,}" . --include="*.py" --include="*.md" --include="*.json" --include="*.yaml"
grep -rniE "(ghp_|gho_|ghs_|sk-|xox[baprs]-|glpat-)[A-Za-z0-9_-]{16,}" .
# 硬编码密码 / 密钥
grep -rniE "(password|passwd|api_?key|client_?secret|app_?secret|access_?token)[\"']?\s*[:=]\s*[\"'][^\"']{6,}" .
# 真实 Cookie（微博登录态）
grep -rniE "(SUB|SUBP|SSOLoginState|ALF)[=:]\s*[\"']?[A-Za-z0-9_%\-]{8,}" .
```

> 注意：本插件**不使用也不需要**微博 Cookie，`custom_cookie` 默认空。
> 代码里出现的 `SUB`、`_T_WM`、`XSRF-TOKEN` 都是**变量名或空值**，属正常。

- [ ] 无命中（或命中项已逐条确认是变量名 / 占位符 / 测试假值）

### 3.2 个人信息与本机痕迹

```bash
grep -rniE "[A-Za-z]:\\+Users|[A-Za-z]:/Users|/Users/[A-Za-z]+|/home/[A-Za-z]+" .
grep -rniE "[A-Za-z]:\\+项目|[A-Za-z]:/项目|adsm|workbuddy" .
grep -rnoE "[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}" . | grep -v "noreply.github.com"
```

- [ ] 无本机绝对路径、无本机用户名
- [ ] 邮箱只允许 `*@users.noreply.github.com` 这类隐私保护形式
- [ ] 无手机号 / 身份证号 / 银行卡号

> **缓存目录是常见漏点**：`.ruff_cache/` 会记录本机绝对路径，
> `.pytest_cache/` 会记录用例节点 id。二者虽已被 `.gitignore` 覆盖，
> 但发布前建议直接删掉，避免误用 `git add -f` 或打包时被带上：
>
> ```bash
> find . -type d \( -name "__pycache__" -o -name ".pytest_cache" -o -name ".ruff_cache" -o -name "data" \) -prune -exec rm -rf {} +
> ```

### 3.3 二进制与资源文件

- [ ] `logo.png` 不含 `tEXt` / `iTXt` / `eXIf` 等元数据块
      （否则可能反推出生成工具或提示词）

```bash
python -c "
import struct, pathlib
b = pathlib.Path('logo.png').read_bytes(); pos, out = 8, []
while pos < len(b):
    ln = struct.unpack('>I', b[pos:pos+4])[0]; out.append(b[pos+4:pos+8].decode('latin1')); pos += 12 + ln
print([c for c in out if c in ('tEXt','iTXt','zTXt','eXIf','tIME')] or '无元数据块')
"
```

### 3.4 运行期数据不进仓库

- [ ] 仓库内无 `*.db` / `*.jsonl` / `*.log` / `.env*` / `*.session` / `uncovered.jsonl`
- [ ] 确认 `.gitignore` 已覆盖：`data/`、`*.db`、`*.jsonl`、`*.log`、`.env*`、`*.session`


## 五、插件规范自检

```bash
# 目录名必须等于 metadata.yaml 的 name
python -c "
import re, pathlib
md = pathlib.Path('metadata.yaml').read_text(encoding='utf-8')
print('目录名 == name:', pathlib.Path('.').resolve().name == re.search(r'^name: (\S+)', md, re.M).group(1))
print('version 带 v 前缀:', bool(re.search(r'^version: v', md, re.M)))
print('astrbot_version 不带 v:', not re.search(r'astrbot_version: \"?v', md))
"
# 配置项 type 必须是受支持取值
python -c "
import json
s = json.load(open('_conf_schema.json', encoding='utf-8'))
ok = {'string','text','int','float','bool','object','list'}
print('非法 type:', {k:v.get('type') for k,v in s.items() if v.get('type') not in ok} or '无')
print('是否误用 requests / 自建 logging:')
"
grep -rnE "^\s*(import|from)\s+(requests|logging)" --include="*.py" . | grep -v tests/ || echo "  无违规"
```
